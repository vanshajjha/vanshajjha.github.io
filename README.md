# vanshajjha.github.io

Personal HR blog of Vanshaj Kumar Jha, built with Jekyll on GitHub Pages.

- Posts live in `_posts/` as `YYYY-MM-DD-slug.md`.
- `_editorial/` holds the style guide, topic backlog, editorial rules and the brief the weekly drafting agent follows. It is excluded from the public site.
- New posts arrive as pull requests. Merging a pull request publishes the post.
